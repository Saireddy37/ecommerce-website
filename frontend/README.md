# Shopwise frontend (React + Vite)

1. Put this `frontend` folder next to your `backend` folder.
2. Terminal 1 (backend):   cd backend  &&  node server.js
3. Terminal 2 (frontend):  cd frontend &&  npm install  &&  npm run dev
4. Open http://localhost:5173

Requests to /api/... are forwarded to http://localhost:5000 (see vite.config.js).
On Windows PowerShell, if npm is blocked, use npm.cmd instead of npm.
